# ババ抜きゲーム ルール

## 概要

4人対戦のババ抜きゲーム。最初に手札をなくした人が勝ち。

## プレイヤー

- 1ゲーム4人固定

## ゲームの流れ

### 1. マッチング

- グローバルに1つのマッチメイキングキューが存在する（DynamoDB上で `PK=MATCHMAKING` のパーティション）
- クライアントが `join` メッセージを送信すると、プレイヤーがキューに追加される
- キュー内が4人未満の間は、待機中の全プレイヤーに `waiting` メッセージ（`waitingCount` 付き）が送信される
- 4人集まった時点で先着4人をキューから取り出し、ゲームが自動的に開始される
- 5人目以降のプレイヤーはキューに残り、再び4人集まるまで待機する（別のルームとして開始される）
- ルームID指定や友達招待の仕組みは現時点では存在しない

#### テーマルーレット演出

マッチング待機中、プレイヤーが1人参加するごとにテーマルーレットのスロットが1つずつ確定する。スロットは `who → when → where → what` の順に決まり、4人揃った時点で4つすべてが確定する。

| スロット | カテゴリ | 候補 (各5つ) |
| -------- | -------- | ------------ |
| 0        | who      | Aさんが / Bさんが / Cさんが / みんなで / あなたが |
| 1        | when     | 社会人のとき / 子供のとき / 夏休みに / 深夜に / 朝一で |
| 2        | where    | 家で / 学校で / 海辺で / 宇宙で / 森の中で |
| 3        | what     | さみしかった話 / 笑った話 / 驚いた話 / 冒険した話 / 食べた話 |

確定したテーマは `waiting` メッセージの `decidedSlots` / `newSlot` フィールドでクライアントに通知される。ルーレット状態はゲーム開始時に削除される。

### 2. カード配布

- ジョーカーを1枚含むトランプから、各プレイヤーに5枚ずつ配る
- 配布後、手札に同じ数字のペアがあれば自動的に捨てる

### 3. ゲーム進行

- 時計回りの順番でターンが進む
- 自分のターンでは、次のプレイヤー（右隣）の手札から1枚引く
  - 相手の手札は裏向きで表示され、どのカードかはわからない
- 引いたカードと手札でペアができたら、そのペアを捨てる

### 4. 勝敗

- **最初に手札がなくなったプレイヤーが勝ち**
- ジョーカーが最後まで残ったプレイヤーが負け
